# 关于todo板块的说明
ToDo是本系统的一个板块，我们的系统支持多用户使用这个板块。关于它的基本信息：
* 一个ToDo item包括标题、描述、优先级、重要程度、截止时间、分类、标签、状态
* 状态包括未完成、暂停中、已完成
* 优先级总的分五档，重要程度也分五档
* 分类是可自定义的，支持嵌套子分类
* 标签是可自定义的

## 本机草稿（Plan 025）

管理端与移动端的新建、编辑事项均自动保存完整表单。输入后约 400 毫秒保存一次，关闭编辑器、提交、离开页面及切到后台前补存；可在“本机草稿”列表继续编辑。关闭表示保留草稿，只有提交成功或明确确认“丢弃草稿”才清理当前草稿。

登录过期时先保存草稿，再跳转登录。登录原账号后回到对应编辑框，仍由用户手动提交；密码输错不会丢掉返回位置。网络失败、服务器错误和超时不会删除草稿，超时后应先查看事项列表再决定是否重试。

草稿仅保存在当前浏览器，管理端与移动端分别保存，不跨设备同步；清除站点数据会移除草稿。存储空间不足或不可用时会明确报错，阻止应用内关闭或跳转，并提供全文复制和下载备份。强制结束浏览器、清除数据及未完成的图片上传不在保证范围内。

不同账号的草稿互相隔离；另一窗口正在编辑同一份草稿时打开独立副本。浏览器不支持独占锁时也使用独立副本并保留原稿，列表中可能出现多份草稿。恢复旧编辑稿或保存前若发现原事项已经更新、删除或无权访问，会保留草稿并提示核对，可另存为新事项。
